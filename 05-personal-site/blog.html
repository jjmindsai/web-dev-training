I put a website on the internet

17 September 2026

I started out learning HTML and CSS, then moved on to JavaScript, Node, npm, Python, and Flask. I saved my projects on GitHub and used GitHub Pages to publish the website.

The live website is a static site built with HTML, CSS, and JavaScript. For contact forms and other backend features, I use Flask or Express with SQLite on my local PC. The backend runs locally and is not part of the public website.

Live site: jjmindsai.github.io/web-dev-training.
